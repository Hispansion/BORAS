# Notebooks

This folder contains the experiment notebooks used to run specific BORAS test cases and validation scenarios.

- `TSP_SPP_v2.ipynb` is the main workflow notebook.
- The remaining notebooks are preserved as useful experiment records and targeted test runs.

For the main workflow, follow the three-file instructions in the repository [README](../README.md). `TSP_SPP_v2.ipynb` reads `configs/input_config.txt` by default and resolves map paths from the repository root.

Launch Jupyter from the repository root so older experiment notebooks with repository-relative paths also work.
